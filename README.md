# مغامرة نورلين 🌸

لعبة عربي وحساب للأطفال (٤ سنين) بتتكلم بصوت الجهاز. React + Vite، من غير سيرفر ولا حسابات ولا إعلانات.

## تشغيل على جهازك
محتاجة Node.js (إصدار 18 أو أحدث).

```
npm install
npm run dev
```
افتحي الرابط اللي هيظهر (غالبًا http://localhost:5173).

## تجربة النسخة النهائية
```
npm run build
npm run preview
```
الملفات الجاهزة بتتحط في فولدر `dist`.

## النشر (من غير ما نكون نشرنا فعلًا)
**Vercel:** ارفعي المشروع على GitHub، وادخلي vercel.com واختاري المشروع. الإعدادات: Build = `npm run build`، Output = `dist`.

**Firebase Hosting:**
```
npm install -g firebase-tools
firebase login
firebase init hosting     # اختاري فولدر dist، و Single-page app = Yes
npm run build
firebase deploy
```
لازم تفتحي الرابط على موبايل/تابلت حقيقي وتجربي الصوت قبل ما تدّيها للبنت. (الصوت محتاج HTTPS أو localhost.)

## تغيير الاسم والشخصية
- الأسماء: ملف `src/config.js` → `HERO_NAME` (الاسم الحقيقي) و `PRAISE_NAME` (اسم الدلع في المدح). الاتنين بيتغيّروا في كل اللعبة.
- شكل الشخصية: `src/art/Hero.jsx` و `src/art/Bunny.jsx` (رسم SVG بسيط مبني على وصف الصورة، مش نسخة طبق الأصل).

## تغيير المحتوى
- الحروف والكلمات: `src/data/letters.js`
- الأرقام: `src/data/numbers.js`، الألوان والأشكال: `src/data/colorsShapes.js`
- جمل المدح والتشجيع: `src/data/phrases.js`
- ترتيب المراحل وعدد الأسئلة: `src/data/curriculum.js`
- بعد أي تعديل: `npm run verify` بيفحص إن المحتوى سليم (إجابة صحيحة واحدة لكل سؤال، إلخ).

## منطقة الأهل
اضغطي مطوّلًا ٣ ثواني على أيقونة الأهل ثم أكدي. جواها:
- **التقدّم:** المراحل المكتملة، "اتدربت على" و"محتاجة مراجعة"، وإعادة فتح أي تدريب.
- **الصوت:** اختبار الصوت ومراجعة نطق كل حرف. أصوات الحروف مش بتتعلّم كنطق غير بعد ما تسمعيها وتوافقي عليها.
- **الإعدادات:** سرعة الصوت، الموسيقى، تقليل الحركة، وضع "الأهل بيقروا" لو مفيش صوت عربي، وفتح كل المراحل.
- **البيانات:** مسح التقدّم (بتأكيد تاني).

## الخصوصية
كل حاجة بتتحفظ في المتصفح (localStorage) على الجهاز بس. مفيش حسابات ولا تتبّع ولا ميكروفون ولا كاميرا ولا موقع. التقدّم مش بيتزامن بين الأجهزة، وممكن يضيع لو مسحتي بيانات المتصفح. بعض أصوات الأجهزة ممكن تحتاج إنترنت.

## حدود لازم تعرفيها
- الصوت بيعتمد على أصوات العربي الموجودة في جهازك. لو مفيش صوت عربي، اللعبة بتنبّهك وتقترح متصفح/جهاز تاني أو وضع "الأهل بيقروا".
- جودة نطق الحروف بتختلف من جهاز للتاني، راجعيها بنفسك.
