# مغامرة نورلين 🌸

لعبة عربي وحساب للأطفال (٤ سنين) بتتكلم بمقاطع صوت مصرية جاهزة (mp3). React + Vite، من غير سيرفر ولا حسابات ولا إعلانات.

## تشغيل على جهازك
محتاجة Node.js (إصدار 18 أو أحدث).

```
npm install
npm run dev
```
افتحي الرابط اللي هيظهر (غالبًا http://localhost:5173).

## تجربة النسخة النهائية
```
npm run build
npm run preview
```
الملفات الجاهزة بتتحط في فولدر `dist`.

## النشر (من غير ما نكون نشرنا فعلًا)
**Vercel:** ارفعي المشروع على GitHub، وادخلي vercel.com واختاري المشروع. الإعدادات: Build = `npm run build`، Output = `dist`.

**Firebase Hosting** (ملف `firebase.json` جاهز في المشروع):
```
npm install -g firebase-tools
firebase login
firebase use --add        # اختاري مشروع Firebase (أو اعملي مشروع جديد من console.firebase.google.com)
npm run build
firebase deploy --only hosting
```
لازم تفتحي الرابط على موبايل/تابلت حقيقي وتجربي الصوت قبل ما تدّيها للبنت. (الصوت محتاج HTTPS أو localhost.)

## تغيير الاسم والشخصية
- الأسماء: ملف `src/config.js` → `HERO_NAME` (الاسم الحقيقي) و `PRAISE_NAME` (اسم الدلع في المدح). الاتنين بيتغيّروا في كل اللعبة.
- شكل الشخصية: صور نورلين في `public/images/noorleen/` (`idle.png` و `happy.png` و `encourage.png`) والكومبوننت `src/art/NoorleenHero.jsx`. لو غيّرتي الصور خليهم PNG شفاف بنفس الأسماء، أو عدّلي الامتداد في أول الملف. رسم الـ SVG القديم (`Hero.jsx`) بيظهر بس لو `idle.png` ناقصة.

## تغيير المحتوى
- الحروف والكلمات: `src/data/letters.js`
- الأرقام: `src/data/numbers.js`، الألوان والأشكال: `src/data/colorsShapes.js`
- جمل المدح والتشجيع: مقاطع جاهزة، واختيارها في `src/audio/clips.js`
- ترتيب المراحل وعدد الأسئلة: `src/data/curriculum.js`
- بعد أي تعديل: `npm run verify` بيفحص إن المحتوى سليم (إجابة صحيحة واحدة لكل سؤال، إلخ).

## منطقة الأهل
اضغطي مطوّلًا ٣ ثواني على أيقونة الأهل ثم أكدي. جواها:
- **التقدّم:** المراحل المكتملة، "اتدربت على" و"محتاجة مراجعة"، وإعادة فتح أي تدريب.
- **أصوات الحروف:** سماع اسم كل حرف وكلمته (تسجيلات جاهزة) وصوته المنفرد (صوت الجهاز). الصوت المنفرد مش بيتعلّم غير بعد ما تسمعيه وتوافقي عليه.
- **الإعدادات:** الموسيقى، المؤثرات، تقليل الحركة، اسم الدلع في التشجيع، وفتح كل المراحل.
- **البيانات:** مسح التقدّم (بتأكيد تاني).

## أيقونة اللعبة
أيقونة اللعبة (التبويب وشاشة الموبايل الرئيسية) من صورة وش نورلين: `public/icons/` (favicon و apple-touch-icon و 192 و 512). لتغييرها بدّلي الملفات بنفس الأسماء. ملف `manifest.webmanifest` بيتولّد تلقائيًا باسم اللعبة من `src/config.js`. على الموبايل: من قائمة المتصفح اختاري "إضافة إلى الشاشة الرئيسية".

## الصوت
- كل الكلام من ملفات `public/audio/*.mp3` (١٣٣ مقطع). مرجع المفاتيح والنصوص الوحيد: `src/audio/manifest.json`.
- الخدمة: `src/audio/audioService.ts` (`playClips(['q_where_letter','letter_01'])`). ربط بيانات اللعبة بالمفاتيح: `src/audio/clips.js` و `src/audio/sequences.js`.
- مقطع ناقص أو ملف مش موجود: بيتخطى بصمت وتحذير في الكونسول بس.
- صوت الجهاز (speechSynthesis) احتياطي صامت: بيشتغل بس لو ملف فشل يتحمّل، ولو مفيش صوت عربي مفيش حاجة بتحصل.
- لو غيّرتي `PRAISE_NAME` لاسم مالوش تسجيل، التشجيع بيستخدم المقاطع اللي من غير اسم بس. تغيير الاسم الحقيقي للصوت = تسجيل مقاطع جديدة.
- مقطع جديد: حطي ملف `اسم_المفتاح.mp3` في `public/audio` وأضيفي المفتاح والنص في `manifest.json`، وبعدين `npm run verify`.
- تقرير مواضع التركيب المشكوك فيها: `AUDIO-REPORT.md`.

## الخصوصية
كل حاجة بتتحفظ في المتصفح (localStorage) على الجهاز بس. مفيش حسابات ولا تتبّع ولا ميكروفون ولا كاميرا ولا موقع. التقدّم مش بيتزامن بين الأجهزة، وممكن يضيع لو مسحتي بيانات المتصفح. صوت الحرف المنفرد (لو اتعتمد) بصوت الجهاز وممكن يحتاج إنترنت.

## حدود لازم تعرفيها
- المقاطع اتجرّبت تقنيًا (تسلسل، فواصل، إلغاء) لكن مش بالودن: لازم تسمعي الجمل المركبة بنفسك (شوفي AUDIO-REPORT.md).
- أول لمسة (زر "يلا نلعب") هي اللي بتفتح الصوت على الموبايل. بعد refresh أو رجوع من الخلفية أول لمسة بتفتحه تاني.
